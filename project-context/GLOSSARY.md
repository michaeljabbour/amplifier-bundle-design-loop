# Glossary

| Term | Meaning | Does not mean |
|---|---|---|
| Run | One input and execution with its own ID and directory | A session-wide mutable result |
| Baseline | Original pass-zero scorecard and artifact | Latest champion |
| Champion | Best accepted candidate | Automatically ready to ship |
| Converged | Gate reason is `bar_met` | Any terminal `DONE` action |
| DRY | Scripted subjective scores plus a real input audit | Real model critique |
| Milestone | First valid observed output for a phase | Every pass or tool call |
